# Wellness Tracker 📱

## Overview

Wellness Tracker is an Android mobile application developed to help users manage their daily wellness activities. The application allows users to track habits, monitor moods, manage hydration goals, and maintain a healthier lifestyle through a simple and user-friendly interface.

This project was developed using Kotlin and Android Studio as part of academic learning in mobile application development.

## Features

### Habit Tracking

* Add new habits
* Mark habits as completed
* Track daily progress
* Delete habits

### Mood Journal

* Record daily moods
* View mood history
* Monitor emotional well-being

### Hydration Tracking

* Track daily water intake
* Set hydration goals
* Receive reminders and notifications

### Dashboard

* View wellness statistics
* Monitor daily progress
* Quick overview of activities

### Settings

* Manage application preferences
* Configure notifications

## Prerequisites

Before running the application, install:

* Android Studio
* Android SDK
* JDK 11 or above

## How to Run

### Clone Repository

```bash
git clone https://github.com/harindimaheshika710-cell/Wellness-Tracker.git
```

### Open Project

1. Open Android Studio
2. Select **Open Project**
3. Choose the cloned project folder

### Sync Gradle

Allow Android Studio to download required dependencies.

### Run Application

1. Connect an Android device or start an emulator
2. Click **Run ▶**
3. Install and launch the application
